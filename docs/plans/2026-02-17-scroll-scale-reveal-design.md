# Scroll Scale-Up Reveal Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add an iPhone-style scroll-driven scale-up reveal to RAVEN-Concept.png with staggered caption and description fade-in.

**Architecture:** Scroll-event listener throttled via `requestAnimationFrame` calculates a 0-1 progress value based on how far the concept section has scrolled into view. This progress drives CSS `transform: scale()` and `opacity` on the image. Caption and description use CSS transitions triggered by adding a `.visible` class at ~80% progress. No libraries.

**Tech Stack:** Vanilla HTML5, CSS3, JavaScript (ES6+) — same as existing project.

### Task 3: Add scroll-driven animation JavaScript

Add a scroll handler that calculates progress and interpolates image scale/opacity. Triggers caption/description visibility at 80% progress.

**Files:**
- Modify: `script.js:105-118` (insert before the smooth scroll section)

**Step 1: Add the concept scroll animation code**

Insert the following block in `script.js` after the metric counter code (line 105) and before the smooth scroll code (line 107):

```javascript
    // --- Concept image scroll-driven scale reveal ---
    const conceptSection = document.getElementById('concept');
    const conceptImg = conceptSection ? conceptSection.querySelector('.concept-img') : null;
    const conceptCaption = conceptSection ? conceptSection.querySelector('.concept-caption') : null;
    const conceptDesc = conceptSection ? conceptSection.querySelector('.concept-description') : null;

    if (conceptImg) {
        // Detect mobile for reduced scale range
        const isMobile = window.matchMedia('(max-width: 768px)').matches;
        const scaleStart = isMobile ? 0.92 : 0.85;
        const scaleEnd = 1;
        const opacityStart = 0.6;
        const opacityEnd = 1;
        let ticking = false;

        function updateConceptScroll() {
            const rect = conceptSection.getBoundingClientRect();
            const windowH = window.innerHeight;

            // Progress: 0 when section top enters viewport bottom, 1 when section top reaches viewport center
            const start = windowH;
            const end = windowH * 0.3;
            const progress = Math.min(Math.max((start - rect.top) / (start - end), 0), 1);

            // Ease-out cubic for smoother feel
            const eased = 1 - Math.pow(1 - progress, 3);

            const scale = scaleStart + (scaleEnd - scaleStart) * eased;
            const opacity = opacityStart + (opacityEnd - opacityStart) * eased;

            conceptImg.style.transform = `scale(${scale})`;
            conceptImg.style.opacity = opacity;

            // Reveal caption and description at 80% progress
            if (eased > 0.8) {
                if (conceptCaption) conceptCaption.classList.add('visible');
                if (conceptDesc) conceptDesc.classList.add('visible');
            }

            ticking = false;
        }

        window.addEventListener('scroll', () => {
            if (!ticking) {
                requestAnimationFrame(updateConceptScroll);
                ticking = true;
            }
        }, { passive: true });

        // Run once on load in case section is already in view
        updateConceptScroll();
    }
```

Key logic:
- `progress` goes from 0 (section entering viewport at bottom) to 1 (section top at 30% from top of viewport)
- Ease-out cubic makes the final approach to full-size feel smooth
- `ticking` flag ensures only one rAF is queued at a time
- Caption/description get `.visible` at 80% eased progress
- Runs once on load to handle page refreshes mid-scroll
